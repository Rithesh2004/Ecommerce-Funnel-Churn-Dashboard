# E-Commerce Funnel & Churn Dashboard

An end-to-end data analytics project tracking user retention, sales funnel conversion bottlenecks, and customer churn drivers using SQL, Python, Tableau, and Excel.

## 📊 Project Overview
This project analyzes an e-commerce transaction dataset to identify where users drop off along the conversion funnel and what key factors contribute to customer churn. 

## 🛠️ Tech Stack & Tools
- **Database & Querying:** SQL (MySQL / PostgreSQL)
- **Data Cleaning & Manipulation:** Python (Pandas, NumPy)
- **Data Visualization & Dashboards:** Tableau, Microsoft Excel
- **Analysis Techniques:** Funnel Analysis, Exploratory Data Analysis (EDA), Retention Cohort Tracking

## 📈 Key Insights & Business Recommendations
- **Funnel Drop-off:** Identified that the highest user drop-off occurs between the product-page view and cart-addition stage (~45% drop).
- **Churn Drivers:** Analysis revealed that customers with inactive history over 30 days and zero promotional engagement have a 3.5x higher likelihood of churning.
- **Strategic Actions:** Recommended targeted re-engagement email campaigns and streamlined checkout steps to improve overall conversion rates.

## 📁 Repository Structure
- `sql_queries/`: Contains all data extraction and aggregation queries.
- `python_scripts/`: Jupyter Notebooks used for data preprocessing and cleaning.
- `dashboard/`: Visual exports and layout previews of the Tableau/Excel dashboards.
